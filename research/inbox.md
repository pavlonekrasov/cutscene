# Reference inbox

Drop a reel here when you find one worth learning from: one per line, an X post, a YouTube or Vimeo
link, a page with a video on it, or a path to a file on this machine. Add a note after a dash when
there's something specific to look at; the breakdown has to answer it.

```
- https://x.com/… — how do they get from the list to the record without a long move?
```

Say "break down the inbox" in a session, or wait for the monthly run. Each one gets measured with
`cutscene measure`, read frame by frame into `breakdowns/`, and what it teaches goes into
`craft.md`. X links wait for a session you're signed in to.
